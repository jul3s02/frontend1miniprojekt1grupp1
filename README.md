# Café Solsidan ☕

Välkommen till repositoryt för **Café Solsidan**! Detta är det första miniprojektet i kursen **Frontend 1**, utvecklat av **Grupp 1**.

## 📌 Om projektet
Café Solsidan är en webbplats framtagen som ett övningsprojekt för att bygga en modern, responsiv och användarvänlig cafémeny samt webblayout. Projektet fokuserar på att tillämpa grundläggande koncept inom frontend-utveckling.
